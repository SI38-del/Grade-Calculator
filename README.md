# Grade-Calculator
A simple and interactive Grade Calculator built using HTML, CSS, and JavaScript. This project allows users to enter their marks for different subjects and instantly calculates:  ✔ Total Marks ✔ Percentage ✔ Final Grade (A, B, C, D, Fail) ✔ Result Status (Pass/Fail)
This project is beginner-friendly and great for learning DOM manipulation, form handling, and basic JavaScript logic.
Features:

✔ Easy-to-use interface

✔ Real-time grade calculation

✔ Input validation (0–100 only)

✔ Responsive UI

✔ Customizable grade rules

🛠️ Technologies Used

HTML5 – Page structure

CSS3 – Styling & layout

JavaScript (ES6) – Logic and dynamic calculations
